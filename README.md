# Sidechat：DeepSeek Harness 侧边临时会话

[English](README_EN.md)

为 DeepSeek Harness 提供与主对话界面一致的侧边临时会话。围绕当前任务追问、阅读文件、理解代码，让主对话继续处理任务。

## 功能

- **原生界面**：模型选择、推理等级、输入框、等待状态、思考过程和流式回答沿用 Harness 主对话组件。
- **上下文追问**：打开时承接主对话的文字上下文；选中文字后点击“提问”，即可带着引用继续讨论。
- **独立模型**：初始模型和推理等级跟随主对话，之后可在侧边独立切换。
- **只读解答**：可读取文本文件、列出目录和搜索内容；不修改文件、不执行命令、不委派任务。可以讨论修改方案，实际操作交给主对话。
- **临时记录**：连续追问保留在同一会话；关闭“临时追问”标签后停止生成并清除该会话的本地记录与草稿。
- **保留讨论位置**：收起侧栏、切换侧栏标签或切换主对话时保留临时会话。

## 安装

当前版本：**1.3.2**。已验证环境：DeepSeek Harness **0.2.1-rc.2** 的 Web 界面，Node.js **20 或以上**。

1. 从 [Releases](https://github.com/YunMo-yanyu/dsh-sidechat/releases/latest) 下载 `dsh-sidechat-1.3.2.tgz`。
2. 安装到 Web profile：

   ```sh
   dsh plugin --profile web add /path/to/dsh-sidechat-1.3.2.tgz
   ```

3. 重启 Harness，并刷新浏览器。

包名为 `dsh-sidechat`。升级前建议备份 Web profile 配置。每个 profile 只需加载一次。

## 使用

1. 在主对话中打开“临时追问”，或选中对话文字后点击“提问”。
2. 在侧边输入问题。需要查看文件时，提供文件路径或说明要查找的内容。
3. 继续追问，或切换侧边模型。主对话的模型和草稿保持独立。
4. 讨论结束后关闭“临时追问”标签。再次打开时会创建新的空白会话。

侧边会话固定显示“只读解答”，不提供权限切换。修改请求会引导回主对话处理。

## 文件与会话行为

- 相对文件路径以打开时主对话的工作目录为基准；也支持绝对路径。
- 支持 UTF-8 文本，每个文件上限 2 MiB，单次读取最多 2000 行，可分页继续读取。
- 内容搜索采用字面字符串，跳过二进制、超限文件及 `.git`、`node_modules`、`.dsh` 目录。搜索和输出有规模限制，结果会标明截断或跳过。
- 主对话上下文是打开时的文字快照，不自动同步后续消息，也不复制图片或工具原始输出。
- 刷新或离开网页会结束该页面的临时会话；异常退出残留的已登记临时记录会在服务下次启动时清理。
- 本地记录清理仅针对本插件创建的临时会话，不改变模型服务商的数据保留规则。

## 开发

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm pack
```

维护宿主兼容性时，可将 `DSH_INSTALL_ROOT` 设为 Harness 包的绝对路径后运行 `pnpm test`，同时检查真实宿主的兼容性门禁、插件展示信息和配置引用接口。

工具执行限制和文件只读策略共同约束模型操作。第三方插件在宿主中运行的受信任代码不属于操作系统级隔离范围。

Harness 升级后，请重新验证原生嵌入接口、只读策略和 JSONL 临时记录清理接口。详细检查见 [VALIDATION.md](VALIDATION.md)。CI 配置示例位于 `.github/ci.example.yml`。
